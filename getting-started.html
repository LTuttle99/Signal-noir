Getting started

Signal Noir in two minutes

Give Signal Noir your data and tell it what you need. It plans the analysis, runs it on your device, and shows the evidence for every number.

01Add data

Drop CSV, Excel, JSON or a ZIP of files onto the box on the home page or into Studio. Files are read inside your browser; nothing is uploaded. Excel workbooks with several sheets ask which one to use, and messy exports with title rows are handled automatically.

02Ask Vanessa

Describe the outcome, not the tool: “why did sales drop last month?”, “compare these two files”, “clean this dataset”, “forecast next quarter”. Vanessa shows an execution plan: import, validate, clean, join, analyze, visualize, report, act. Each step lights up as it actually runs.

Vanessa never changes your data without asking. Cleaning fixes and joins are offered for review and always create a new copy.

03Inspect the evidence

Every finding has an Evidence button showing the source dataset, rows used, filters, the exact calculation, the method, when it was generated and whether it’s a computed value or a statistical estimate. If something wasn’t calculated, Signal Noir says so.

04Keep what’s useful

Save findings, create reports and dashboards, and turn suggestions into tasks and decisions. They collect under Outputs in each project and in the Library across projects. Reports and dashboards download as single HTML files you can share.

05Use the tools directly

Prefer to drive? The tool library has 26 focused utilities: SQL Workbench, Statistical Tests, Fuzzy Duplicate Finder, Dashboard Builder, JSON and regex tools and more. Any data tool can hand its file to Studio with Continue in Studio. Press ⌘ K (Ctrl K on Windows) anywhere to jump to a tool or action.

06Where your data lives

Every project is in Local mode: stored in this browser’s IndexedDB and never sent to a server. Export a project bundle from Studio or Settings to move it or back it up. Private Cloud sync and Team collaboration are planned and clearly marked as not available yet.

  • Only CDN libraries (SheetJS, Chart.js and similar) and fonts are downloaded. They never carry your data.
  • A Google Sheets or web URL connection is fetched directly by your browser, only when you add one.
  • The optional live chat room uses a Supabase project you configure yourself.
