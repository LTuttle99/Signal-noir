Vanessa

Every number Vanessa reports is calculated by Signal Noir’s own engine on this device. A language model is optional: it only helps route unclear requests and write clearly labeled interpretations, and it receives column names, types and calculated results — never your rows.

◍Your access profile doesn’t include letting Vanessa use a language model, so she reasons with the deterministic rules engine only. Every number she reports is calculated either way.
Debug loggingLogs routing decisions, plans and tool timings to the browser console. Dataset contents are never logged.

Your access

Signal Noir is free and nothing is locked behind payment. When several people share an install, an organization can group them into teams and give each team an access profile, so each person sees the part of Signal Noir relevant to their job.

Sample organizationA clearly labelled example with five teams, so you can see how the interface adapts.
Reset all access settingsRemoves every organization, team, member and access profile from this browser. Your projects and data are untouched.
⚠Access shapes the interface; it is not enforced security. Signal Noir runs entirely in this browser, so anyone technical can bypass these checks. Real enforcement needs a server, which Signal Noir does not have yet.
