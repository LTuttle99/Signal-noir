Live team room

      
Connect the same Supabase project and room on each device. Messages use Realtime Broadcast and remain saved locally in each participant’s Signal Noir project.

      
Show the 3-step setup
  1. Create or open a Supabase project.
  2. In Project Settings → API, copy the Project URL and publishable/anon key.
  3. Every teammate enters those values and the exact same room name here.

      
      
      
      
      

      
Room access: anyone with the project URL, publishable key, and exact room name can join. Do not post confidential data until your Supabase project has appropriate access controls.
