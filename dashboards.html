How saving works

Saving keeps the dashboard's design and, where the numbers are small enough, the computed figures with it. It is stored in this browser only, so it is yours rather than the team's, and clearing site data removes it. A dashboard connected to a Google Sheet reloads live from that sheet every time you open it. One built from a file you picked will show its saved figures, and needs the file attaching again if you want to change what it measures.
